# Licensing and redistribution status

This local review artifact does not grant a public redistribution license.
Before any public release, the author must choose an explicit license for the
reference code and generated figures.

The aggregate competition-derived tables also require a separate
redistribution determination. Until that determination is recorded, they are
provided only as local review material. This package contains no raw messages
or direct participant records.

The plotting dependencies are not bundled and retain their own upstream
licenses. No manuscript template, production model, service client, or third
party paper asset is included.
